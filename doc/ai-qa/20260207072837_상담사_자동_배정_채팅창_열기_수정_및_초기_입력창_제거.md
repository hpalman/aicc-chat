# 상담사 자동 배정 채팅창 열기 수정 및 초기 입력창 제거

**작성일시**: 2026-02-07 07:28:37

## 1. 개요

이전 구현에서 상담사 자동 배정 시 채팅창이 자동으로 열리지 않는 문제를 수정하고, 상담사 초기 화면에서 불필요한 메시지 입력창과 전송 버튼을 제거합니다.

### 1.1 문제점

1. **채팅창 자동 열기 실패**: 자동 배정 시 상담사 화면에서 채팅창이 자동으로 열리지 않음
   - 원인: `subscribeToRoom`은 탭이 열릴 때만 호출되므로, 탭이 열리지 않은 상태에서는 `AGENT_AUTO_ASSIGNED` 메시지를 받을 수 없음
   - 원인: 시간 기반 감지(5초 이내)가 네트워크 지연이나 타이밍 문제로 인해 불안정함

2. **불필요한 UI 요소**: 상담사가 로그인한 직후 상담을 선택하지 않은 상태에서도 메시지 입력창과 전송 버튼이 표시됨

```javascript
/**
 * 자동 배정된 방이 있는지 확인하고 자동으로 탭 열기
 */
function checkAndOpenAutoAssignedRoom(rooms) {
    const currentAssignedRooms = new Set();
    
    rooms.forEach(room => {
        // 나에게 배정된 방 추적
        if (room.status === 'AGENT' && room.assignedAgent === nickname) {
            currentAssignedRooms.add(room.roomId);
            
            // 새로 배정된 방인지 확인 (이전에 없었던 방)
            if (!previousAssignedRooms.has(room.roomId) && !openTabs[room.roomId]) {
                console.log('✅ 새로 자동 배정된 방 감지, 자동으로 열기:', room.roomId, room);
                openTab(room);
            }
        }
    });
    
    // 현재 배정된 방 목록 업데이트
    previousAssignedRooms = currentAssignedRooms;
}
```

**개선 사항**:
- **시간 기반 감지 제거**: `lastActivity` 기반의 5초 제한을 제거하여 타이밍 문제 해결
- **상태 기반 감지**: 이전 방 목록과 현재 방 목록을 비교하여 새로 배정된 방을 정확하게 감지
- **Set 자료구조 사용**: 효율적인 중복 확인 및 추적

## 4. 개선 사항

### 4.1 자동 배정 감지 안정성 향상

**이전 방식 (시간 기반)**:
- `lastActivity` 기반으로 5초 이내 배정된 방만 감지
- 네트워크 지연이나 서버 처리 시간으로 인해 5초를 초과하면 감지 실패
- 타이밍에 민감하여 불안정

**개선된 방식 (상태 기반)**:
- 이전 배정 목록과 현재 배정 목록을 비교하여 새로 배정된 방 감지
- 시간 제약 없이 정확한 감지 가능
- 네트워크 지연이나 타이밍 문제에 영향받지 않음

### 4.2 UI/UX 개선

**이전**:
- 상담사 로그인 직후 불필요한 입력창과 전송 버튼 표시
- 상담을 선택하지 않은 상태에서도 입력창이 보여 혼란 유발

**개선**:
- 초기 화면에서 입력창 숨김
- 상담 시작 시에만 입력창 표시
- 모든 상담 종료 시 입력창 자동 숨김
- 깔끔하고 직관적인 UI 제공

### 4.3 코드 간소화

**제거된 로직**:
- `subscribeToRoom` 내부의 `AGENT_AUTO_ASSIGNED` 메시지 처리 로직
- 이유: 탭이 열리지 않은 상태에서는 구독이 안 되어 있어 메시지를 받을 수 없음
- 결과: 불필요한 코드 제거로 유지보수성 향상

**단순화된 감지 로직**:
- 방 목록 브로드캐스트만으로 자동 배정 감지
- 이중 안전장치 대신 단일 안정적인 방법 사용
- 코드 복잡도 감소

## 5. 테스트 시나리오

### 5.1 자동 배정 테스트

1. **상담사 로그인**
   - 상담사가 로그인하여 "대기" 모드로 전환
   - ✅ 초기 화면에 입력창이 표시되지 않음

2. **고객 "상담사 연결" 클릭**
   - 고객이 "상담사 연결" 버튼 클릭
   - 서버에서 대기 중인 상담사 자동 배정

3. **상담사 화면 확인**
   - ✅ 채팅창이 자동으로 탭으로 열림
   - ✅ 입력창이 자동으로 표시됨
   - ✅ "자동으로 고객과의 채팅이 배정되어 상담을 시작합니다" 메시지 표시
   - ✅ 즉시 고객과 채팅 가능

4. **상담 종료**
   - 상담사가 탭 닫기 클릭
   - ✅ 모든 탭이 닫히면 입력창이 자동으로 숨겨짐

### 5.2 네트워크 지연 테스트

1. **느린 네트워크 환경**
   - 브라우저 개발자 도구에서 "Slow 3G" 설정

2. **고객 "상담사 연결" 클릭**
   - 메시지 전송 지연 발생

3. **상담사 화면 확인**
   - ✅ 시간 제약 없이 새로 배정된 방 정확하게 감지
   - ✅ 채팅창이 확실하게 자동으로 열림

### 5.3 여러 상담 동시 처리 테스트

1. **상담사가 이미 1개 상담 진행 중**
   - 탭 1개 열려있음, 입력창 표시됨

2. **새로운 고객 자동 배정**
   - 두 번째 고객이 "상담사 연결" 클릭

3. **상담사 화면 확인**
   - ✅ 두 번째 탭이 자동으로 열림
   - ✅ 입력창은 계속 표시됨 (이미 표시 중)

4. **모든 상담 종료**
   - 상담사가 모든 탭 닫기
   - ✅ 마지막 탭이 닫힐 때 입력창 자동 숨김
