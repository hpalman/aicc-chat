# 상담사 자동 배정 시 채팅창 자동 열기 기능

**작성일시**: 2026-02-07 07:18:23

## 1. 개요

고객이 "상담사 연결"을 클릭하여 대기 중인 상담사와 자동으로 연결될 때, 배정된 상담사의 화면에서 다음 기능이 동작하도록 개선:

1. **채팅창 자동 열기**: 상담사에게 배정된 채팅방이 자동으로 탭으로 열림
2. **시스템 메시지 표시**: 상담사의 채팅창에 "자동으로 고객과의 채팅이 배정되어 상담을 시작합니다" 메시지 표시

#### 2.2.2 `chat-agent.html` - 자동 배정 감지 함수 추가

**파일**: `frontend/chat-agent.html`

```javascript
/**
 * 자동 배정된 방이 있는지 확인하고 자동으로 탭 열기
 */
function checkAndOpenAutoAssignedRoom(rooms) {
    rooms.forEach(room => {
        // 나에게 배정된 방이고, 아직 탭이 열려있지 않은 경우
        if (room.status === 'AGENT' && room.assignedAgent === nickname && !openTabs[room.roomId]) {
            // 최근에 배정된 방인지 확인 (5초 이내)
            const now = Date.now();
            const lastActivity = room.lastActivityAt || 0;
            
            if (now - lastActivity < 5000) {
                console.log('✅ 자동 배정된 방 감지, 자동으로 열기:', room.roomId);
                openTab(room);
            }
        }
    });
}
```

**동작 방식**:
1. 방 목록에서 나에게 배정된 방(`status === 'AGENT' && assignedAgent === nickname`) 확인
2. 아직 탭이 열려있지 않은 방만 대상으로 함
3. 최근 5초 이내에 활동이 있었던 방만 자동으로 열기 (오래된 배정은 제외)
4. 조건을 만족하면 `openTab(room)` 호출하여 자동으로 채팅창 열기

## 3. 동작 흐름

### 3.1 전체 프로세스

```
    ↓

```

### 3.2 이중 안전장치

자동 배정 시 채팅창이 확실하게 열리도록 **이중 안전장치**를 구현:

1. **방 목록 브로드캐스트 감지**: `/topic/rooms`로 방 목록이 업데이트될 때 `checkAndOpenAutoAssignedRoom()` 함수가 최근 배정된 방을 감지하여 자동으로 열기
2. **자동 배정 메시지 수신**: `/topic/room/{roomId}`로 `AGENT_AUTO_ASSIGNED` 메시지를 수신하면 탭이 열려있지 않을 경우 자동으로 열기

이 두 가지 방법으로 네트워크 지연이나 메시지 순서 문제가 있어도 채팅창이 확실하게 열리도록 보장합니다.

## 4. 테스트 시나리오

### 4.1 기본 자동 배정 테스트

1. **상담사 로그인**
   - 상담사가 로그인하여 "대기" 모드로 전환
   - 상태: `WAITING`

2. **고객 "상담사 연결" 클릭**
   - 고객이 "상담사 연결" 버튼 클릭
   - 서버에서 대기 중인 상담사 자동 배정

3. **상담사 화면 확인**
   - ✅ 채팅창이 자동으로 탭으로 열림
   - ✅ "자동으로 고객과의 채팅이 배정되어 상담을 시작합니다" 메시지 표시
   - ✅ 상담사 상태가 "상담중"으로 변경
   - ✅ 고객과 즉시 채팅 가능

4. **고객 화면 확인**
   - ✅ "상담원 연결" 버튼이 비활성화됨
   - ✅ "{상담사명} 상담원과 연결되었습니다" 메시지 표시
   - ✅ 채팅 입력창 활성화

### 4.2 여러 상담사 중 자동 배정 테스트

1. **여러 상담사 로그인**
   - 상담사 A, B, C가 모두 "대기" 모드

2. **고객 "상담사 연결" 클릭**
   - 첫 번째 대기 중인 상담사에게 자동 배정

3. **배정된 상담사 화면 확인**
   - ✅ 배정된 상담사의 화면에만 채팅창이 자동으로 열림
   - ✅ 다른 상담사들은 영향 없음

### 4.3 이미 탭이 열려있는 경우 테스트

1. **상담사가 이미 해당 방의 탭을 열어둔 상태**
   - 상담사가 방 목록에서 미리 해당 방을 클릭하여 탭을 열어둠

2. **자동 배정 발생**
   - 고객이 "상담사 연결" 클릭

3. **상담사 화면 확인**
   - ✅ 탭이 중복으로 열리지 않음
   - ✅ 기존 열려있던 탭에 "자동으로 고객과의 채팅이 배정되어 상담을 시작합니다" 메시지만 표시

### 4.4 네트워크 지연 테스트

1. **느린 네트워크 환경 시뮬레이션**
   - 브라우저 개발자 도구에서 네트워크 속도를 "Slow 3G"로 설정

2. **고객 "상담사 연결" 클릭**
   - 메시지 전송에 지연 발생

3. **상담사 화면 확인**
   - ✅ 이중 안전장치로 인해 채팅창이 확실하게 열림
   - ✅ 방 목록 브로드캐스트 또는 자동 배정 메시지 중 먼저 도착하는 것으로 탭 열기

## 5. 주요 개선 사항

### 5.1 사용자 경험 개선

- **상담사의 수동 작업 제거**: 이전에는 상담사가 방 목록에서 수동으로 클릭해야 했으나, 이제는 자동으로 채팅창이 열림
- **즉각적인 상담 시작**: 자동 배정 즉시 상담사가 고객과 채팅을 시작할 수 있어 응답 시간 단축
- **명확한 알림**: "자동으로 고객과의 채팅이 배정되어 상담을 시작합니다" 메시지로 상담사에게 명확한 상황 전달

### 5.2 기술적 개선

- **새로운 메시지 타입**: `AGENT_AUTO_ASSIGNED`를 추가하여 자동 배정 알림을 명확하게 구분
- **이중 안전장치**: 방 목록 브로드캐스트와 자동 배정 메시지 두 가지 경로로 채팅창 자동 열기를 보장
- **타이밍 최적화**: 최근 5초 이내 배정된 방만 자동으로 열어 오래된 배정으로 인한 오동작 방지
- **중복 방지**: 이미 열려있는 탭은 다시 열지 않고 메시지만 표시

### 5.3 확장성

- **다중 서버 환경 지원**: Redis Pub/Sub을 통한 메시지 브로드캐스트로 분산 환경에서도 정상 동작
- **유지보수성 향상**: 자동 배정 로직이 `AgentAssignmentService`에 집중되어 있어 수정 및 확장 용이
